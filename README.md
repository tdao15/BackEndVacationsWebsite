This is my backend project that provides functionality to a vacation package website's front-end. It connects a MySQL database to an angular front-end. 
This project uses:
  > Java
  > Spring Framework + Maven
    - Data JPA
    - Data REST
    - MySQL Driver
    - Lombok
  > Angular
  > MySQL

Project features and details:
  The main functionalities of the website include storing users and their information, customizable travel/vacation packages with excursion combinations to choose from,
  a functioning shopping cart, and functionality for confirming orders and returning a tracking number. This functionality is accomplished by using entities with 
  JPA mappings, implementing REST controllers, using DAO repositories, and custom service methods implementing DTO's. All in all, this was a large project that solidified my
  understanding of how these different aspects (Java, front-end, data, and spring framework as a whole) tie in together. Not only was I able to learn the fundamental concepts, 
  but I was able to learn and apply important methodologies in software development, such as conventions for project setup and structure, the development process, proper data query
  logic to avoid unintentional data writes, and much more. I was forced to reflect, adapt, and innovate as I experienced new concepts, errors, and obstacles in the development process.
